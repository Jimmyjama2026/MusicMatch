# MusicMatch

A music discovery app that recommends songs from your favorites and explains each match.

## Purpose
CS111 project requiring at least 10 hours of actual research, coding, debugging, and testing. Build programming skills and a portfolio project relevant to machine learning and software engineering. AI assistance is allowed.

## First version
- Load a downloaded music dataset with song titles, artists, and available features such as tempo, energy, danceability, and acousticness.
- Let users select a song.
- Scale numerical features and calculate similarity.
- Return five recommendations with understandable explanations.
- Add a simple interface if time allows.

Suggested tools: Python, pandas, scikit-learn, and optionally Streamlit. This content-based recommender does not require a neural network or paid AI API. Verify dataset availability, licensing, and feature coverage before implementation.

## Optional extensions
Choose one initially: a discovery slider, multiple favorite songs, artist diversity, or saved thumbs-up/down feedback. Live music-service integration can come later.

## Evaluation and deliverables
Compare recommendations with a simple baseline, such as same-genre suggestions. Collect user ratings and report actual results and limitations. Include a working demo, README, relevant tests, lessons learned, and an honest time log.

## Starting scope
Aim for roughly 10–15 hours for a first version; unfamiliar tools may require more time. Before starting, review the course requirements, deadline, programming experience, and dataset options.
